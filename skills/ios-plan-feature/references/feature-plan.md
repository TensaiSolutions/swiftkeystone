# Feature plan

Use the app's own planning format when one exists. Otherwise adapt this outline:

- Outcome and bounded scope.
- Observable acceptance criteria.
- Existing implementation and affected components.
- Data/compatibility implications and decisions.
- Implementation sequence.
- Evidence required for each criterion.
- Open questions, assumptions, and explicit exclusions.

Keep decisions next to their rationale. Link to the relevant source locations; do not duplicate a large code inventory. Save only when requested or useful for the authorized work, respecting the project's existing artifact conventions.
